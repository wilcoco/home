# `content/esg.json` — 환경 공시 데이터 원천

`environment.html` 의 환경·안전 실적 표는 이 파일 하나에서 생성됩니다.
페이지의 표를 직접 고치지 마세요. 여기를 고치고 빌드하면 됩니다.

```bash
py -3 tools/build_esg.py       # Windows
python3 tools/build_esg.py     # macOS / Linux
```

표준 라이브러리만 사용합니다 (Python 3.8+). 외부 패키지가 필요 없습니다.
스크립트는 **멱등(idempotent)** 입니다. 같은 JSON 으로 몇 번을 돌려도 결과 HTML 이 바이트 단위로 같습니다.
빌드 후 `git diff` 가 비어 있다면 페이지가 JSON 과 일치한다는 뜻입니다.

## JSON 키 → 워크북 셀 매핑

### `revenue` — 매출액 (億원)
`자원관리 계산` 시트 `A4:G4` (2019~2025). 모든 원단위·집약도의 분모입니다.

### `air` — 대기오염물질
`대기배출오염물질` 시트 `B27:L35`

| JSON | 셀 |
| --- | --- |
| `emission` (2021~2025) | `C`~`G` 열 |
| `intensity_2024` | `H` 열 = 배출량 × 1000 ÷ 매출액(億) |
| `target` | `I` 열 = `H` × 0.97 |
| `intensity_2025` | `J` 열 |
| `vs_target` | `K` 열 = (`J` − `I`) ÷ `I`, **비율**(0.37 = 37%) |
| `note` | `L` 열 (목표 달성 / 목표 초과 / 소폭 초과 / 신규 검출 / 신규 항목) |

35행(총합계)은 원래 `H`·`I`·`J` 수식이 비어 있어 증감이 항상 `-` 로 나왔습니다. 교정본에서 채웠습니다.

### `resources` — 원부자재 · 폐기물 · 재활용
`자원관리` 시트 메인 시계열 `D3:O22`. 연도 열은 `H`(2019) ~ `N`(2025).

| 행 | JSON 키 |
| --- | --- |
| 4, 5, 6, 7 | `bumper_resin`, `paint`, `material_total`, `material_intensity` |
| 8~12 | `gen_recycle`, `gen_incin`, `gen_landfill`, `gen_total`, `gen_intensity` (일반폐기물) |
| 13~17 | `des_recycle`, `des_incin`, `des_landfill`, `des_total`, `des_intensity` (지정폐기물) |
| 18, 19 | `waste_total`, `waste_intensity` |
| 20, 21, 22 | `recycled`, `recycled_intensity`, `recycle_rate` |

폐기물 6개 행은 `자원관리 계산` 시트를 `SUMIFS` 로 집계합니다.
일반은 27~29행, 지정은 30~39행만 봅니다. **42~45행은 함평 사업장이라 하남 집계에서 제외합니다.**

### `ghg` / `energy_inventory` — 온실가스 · 에너지
`온실가스, 온수, 용수` 시트 `Q58:T70`. 열은 `Q`(2019 기준년) `R`(2023) `S`(2024) `T`(2025).
온실가스 배출권 명세서 기준이며 측정 빈도는 연 1회입니다.

### `water` — 용수 · 폐수
같은 시트 `F28:L33`, 열 `F`(2019) ~ `L`(2025). 28행 사용량, 30행 원단위, 33행 폐수 위탁처리량.

### `circularity` — 자원순환 성과
`자원관리 계산` 시트 `AE26:AG33`, `AF`=2024 `AG`=2025.
자원순환기본법 성과관리 산정 기준입니다.

### `energy_billed` — 총 에너지 소비량 (SASB TR-AP-130a.1)

**요금 실적에서 직접 계산합니다. 워크북에 없습니다.**

```
총 에너지(GJ) = 전력 전체 소계(kWh) × 0.0036
              + 도시가스 합계(N㎥) × 0.0418604      ← 10,000 kcal/N㎥ 환산
```

- 전력: `2026년 전력비` 시트, 각 연도 블록의 `합계` 행 **`L`열**(소계 = 캠스 + 2공장 + 데꼴 + 디에프)
- 도시가스: `26년 도시가스` 시트, 각 연도 블록 **`K`열**(합계, N㎥)

주의할 점 두 가지:

1. **청구서의 실제 평균열량(약 42.5 MJ/N㎥, `N`열 사용열량)을 쓰면 기존 공시값과 맞지 않습니다.**
   10,000 kcal 고정계수여야 2022년 +0.07%, 2023년 −0.11% 오차로 일치합니다.
   그래서 2022·2023 은 기존 SASB 공시값을 그대로 두고, 2024·2025 만 같은 식으로 계산했습니다.
2. 가스 시트에 연도 라벨 오타가 있습니다. 26년 블록의 5월·7~12월 행이 `25년` 으로 적혀 있어
   라벨만 믿고 집계하면 2025년이 부풀려집니다. 헤더(`년-월`) 기준 12행씩 끊어야 합니다.

이 값은 `ghg`/`energy_inventory` 의 명세서 기준 에너지(TJ)와 2% 안팎 다릅니다.
산출 근거가 다르기 때문이며, 페이지에서도 두 표를 분리하고 각주로 밝혀 두었습니다.

## 목표 계산 규칙

빌드 스크립트가 JSON 값에서 자동으로 계산합니다. JSON 에 목표를 적지 마세요.

| 구분 | 목표 | 판정 |
| --- | --- | --- |
| 감축 지표 (원부자재, 폐기물, 대기) | 전년 × 0.97 | 실적 ≤ 목표 → `▼` 초록 (달성) |
| 증가 지표 (재활용량, 재활용률) | 전년 × 1.03 | 실적 ≥ 목표 → `▲` 초록 (달성) |

**목표 대비는 총량이 아니라 매출액 기준 집약도(원단위)로 비교합니다.** 워크북 수식과 동일합니다.

## 연도를 하나 넘길 때

1. 워크북에서 새 연도 값을 확인합니다.
2. `content/esg.json` 의 각 시계열에 `"2026": <값>` 을 추가합니다.
3. `air` 는 `intensity_2024`/`target`/`intensity_2025`/`vs_target`/`note` 키 이름이 연도 고정이므로
   한 해씩 밀어 넣습니다. (`tools/build_esg.py` 의 `block_air` 도 같이 손봐야 합니다.)
4. 다른 표는 `block_*` 의 `ys = ["2023", "2024", "2025"]` 기준 연도만 바꾸면 됩니다.
5. 빌드 후 `git diff` 로 표가 의도대로 바뀌었는지 확인하고 커밋합니다.

표는 항상 **최근 3개년 + 목표 + 목표 대비**로 열 수가 고정되므로, 해가 바뀌어도 표가 넓어지지 않습니다.
